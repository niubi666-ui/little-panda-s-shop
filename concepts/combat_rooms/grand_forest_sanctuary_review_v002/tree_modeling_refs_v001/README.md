# 圣庭树木建模参考

本组为内置 imagegen 生成的建模概念参考，沿用古树圣庭的树皮、叶片和苔藓风格。

## 图片

- `01-ancient-oak-four-views.png`：古树四视图，左上 FRONT（正面）、右上 LEFT（左侧）、左下 RIGHT（右侧）、右下 BACK（背面）。展示完整树冠、树干与主根。
- `02-small-forest-trees.png`：三种周边小树候选，从左到右为年轻直立橡树、轻微倾斜分叉树、纤细高树。均为完整独立树体。

采用中性浅灰背景与柔和照明，避免场景阳光、花草和建筑干扰模型轮廓。原场景未完整展示的树冠和背部属于概念补全，不是既有三维模型的测量视图。多视图仍须在建模时统一枝干、树根及树冠的对应关系。

古树建议把树干主根、枝干、树冠叶片分开组织，以便后续调整遮挡和细节。小树具体尺寸尚未确认；提示词中的4–7米仅为概念设计范围。

本轮未改动 Blender 或 Godot。完整提示词见 `prompts.md`。
