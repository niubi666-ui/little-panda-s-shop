## 5. 材质与效果怎么做

以下为起始美术建议，尚未在 Blender 实测，不作为固定项目数值。

| 表面 | 制作方向 |
| --- | --- |
| 干石材 | 米灰石灰岩、细孔与磨损；粗糙度可从 0.65–0.9 起步；浅倒角接高光；避免深黑接缝 |
| 潮湿石材 | 用局部遮罩降低粗糙度并稍微压暗颜色；不要全场湿亮 |
| 浅水洼 | 单独薄水面或局部材质层；不规则边界，平静反射；粗糙度可从 0.03–0.12 起步 |
| 黄铜 | 金属度 1，粗糙度可从 0.25–0.45 起步；边缘亮、凹处略暗，少量氧化 |
| 旗布 | 深森林绿、金色叶纹、细纤维；较高粗糙度；布褶有厚度，避免金属式镜面反光 |
| 叶片 | 叶色有冷暖与明暗变化，薄片透光适度；叶形轮廓与投影清楚，避免整冠一个实心团 |
| 苔藓 | 潮湿凹缝、墙脚与柱底较多；结合材质遮罩与局部小簇，不均匀铺满所有石面 |

## 6. 灯光还原顺序

1. 固定高位斜俯视相机，俯角可从约 45–55° 起步；以 07 的中央空间占比为目标。顶视相机仅检查布局。
2. 设置一个偏暖的太阳主光，从画面左后上方照入，投影伸向右前方；按树影长度调太阳高度。
3. 加偏冷、较弱的天空环境光，使阴影里的石材仍可辨认。先确认石面不会过曝，再加其他效果。
4. 树冠在庭院外侧遮挡太阳，利用真实叶片或合适的叶簇形成疏密交错的树影；不要在石材底色画死影子。
5. 灯笼发光面配少量暖色局部光。白天它们只点缀柱顶与神龛附近，不压过日光。
6. 最后添加局部薄雾或光束，主要放在树冠下与远景；保持中心地面清楚，不用浓雾盖住场景。
7. 加少量边缘浅水洼，检查反射天空和叶片；干石面保持粗糙，湿地与干地有明确差别。
8. 输出相同相机的中性材质检查、仅日光、日光加天空、最终效果四张检查图。以实际渲染对照参考，逐步调整。

## 7. 建议制作顺序与检查

- 第一轮：地面、墙、柱、拱门和神龛灰模；检查通道宽度和中心空地。
- 第二轮：结构细节、中心徽记、石材与布旗；检查模块尺寸与接缝。
- 第三轮：树冠、藤叶、花带、草与落叶；中心少、边缘密，重复对象适当旋转与换尺度。
- 第四轮：日光、树影、天空补光、灯笼光、浅水与少量光束。
- 交付：可编辑对象、材质、相机和灯光；中性光下检查轮廓；游戏视角下检查可读性；不能把概念稿当成已建好的模型。
