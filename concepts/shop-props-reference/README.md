## 生成提示词的共同约束

`stylized-concept`；高位斜俯视、三分之四视角的奇幻店铺 3D 道具参考；深色胡桃木、旧石材、黄铜与手绘质感；柔和暖光；每张图恰好四件道具，按 2×2 排列且互不重叠；浅色中性背景、完整轮廓、留出裁切边距；不要人物、动物、房间场景、文字和标签。原店铺图仅作为视觉与物件参考。

各图主题依次为：木制柜台与货架；门窗及墙面陈设；储物容器与植物展示；灯具、地毯、布幔与药剂托盘；同风格椅凳及魔法陈设。

第 06 张使用同一风格参考，提示词要求“恰好三盆独立窗台植物，按左中右排列并留裁切空隙”：左侧为浓密椭圆绿叶与矮陶盆，中间为紫色花穗、窄叶与高白陶盆，右侧为垂落的黄绿心形叶与深色圆陶盆；不生成窗台、人物、房间或文字。

第 07 张生成三种没有花盆、可挂在书架横梁或灯笼支架上的独立垂叶；第 08 张生成三种完整陈列架，分别放魔法藏品、药剂草药和日常补给；第 09 张生成四件可以摆在柜台或架上的小装饰物。共同提示词保持高位三分之四视角、暖色手绘质感、完整轮廓、各件之间留空，避免人物、房间和文字。
