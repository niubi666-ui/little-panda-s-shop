## 后续讨论与实施注意
- 物品、价格、数值、角色文案和键位为示例，不构成玩法或输入契约变更。
- 背包示例的容量数字与可见物品数量未严格匹配；最终由真实数据驱动。
- HUD 图中同时展示两处交互提示是样式演示；实际优先显示当前交互目标。
- 普通物品移入仓库是否需要确认弹窗尚未决定，图中仅示意弹窗外观。
- 稀有度、选中与禁用状态需兼顾文字或图标提示，避免仅凭颜色识别。
- 图中的编号标题、装饰文字不必进入最终游戏。
- 最终文字必须使用本地化 key 动态呈现，不能将生成图中文字直接烘焙进正式 UI；需要验证英文长度、字体与分辨率缩放。
- 后续补充战斗 HUD、三选一构筑、暂停设置及结算界面；本批聚焦店铺交互。
