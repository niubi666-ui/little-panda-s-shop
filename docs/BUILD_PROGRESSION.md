# 构筑成长：从主打法逐步形成流派

2026-10-16 更新（用户确认“元素觉醒”规则，见第 0 节）。2026-10-15 用户确认的设计方向：保留火、冰、土、雷和六种两两反应，让玩家在一局中逐步形成打法，后续选择持续影响操作、站位、目标选择和技能循环。数值强化仍有价值，但不能覆盖全部后续成长。

## 0. 元素觉醒与奖励来源（2026-10-16 用户确认，优先于本页其他旧表述）

参考《哈迪斯2》的结论：它按“神”分门、进门三张同神祝福、允许替换已占槽位的核心祝福；元素靠“灌注”（持有足够数量同元素祝福才生效）奖励专精；改变武器打法的“代达罗斯之锤”默认每局两次。我们**不照搬按神分门和替换**，而是把元素做成类似“锤子”的重大选择。

### 元素觉醒（决定某个按键带什么元素）

- **每局固定两次**：第一次在冒险开始（第一区第一间之前）；第二次在**第一区 Boss 打完之后**。
- 三个选项从“元素 × 还没有元素的按键（左键 / R / 右键）”里随机抽，例如“火 R / 冰左键 / 雷右键”。**永远不出替换已有元素的选项**，不浪费选择。
- 第二次觉醒保证三个选项里**至少一个与已有元素相同**、**至少一个是新元素**，让“冰左键＋冰右键”和“火左键＋土 R”两条路都选得到。
- 两次之后第三个按键默认没有元素；**第三个元素只能通过稀有途径获得**：地图上的事件房、宝箱房有概率开出“元素觉醒”。具体概率与是否需要代价放配置。
- 闪避不带元素。

### 平时的三选一（构筑卡）

- **从全卡池随机抽三张**，不按元素分门。例如一次可能是“分裂剑气 / 冰寒被动 / R 键范围扩大”。
- 卡池不含元素觉醒。抽取先过合法性（前置、互斥、已满级），再按**相关度加权**：与已有元素、已带元素的按键、已有形态相关的卡权重更高，保证主打法能持续深化；同时保留补其他按键、准备第二元素的机会。
- 同一次三选一里同一个按键最多两张；已无升级空间的卡不再出现。
- 有合法候选时必须选一张再继续；不提供“暂时关闭”。全局元素/反应强化按当前构筑实时读取，可以影响已存在的持续效果（2026-10-16 用户确认保留）。
- 卡的类别：武技改造（分裂、穿透、蓄力、回旋、R 范围、左键延伸……，不需要元素）、元素被动（要求有该元素）、**同元素专精**（要求两个按键都带同一元素，见下）、跨按键联动、反应卡（要求有两种元素）、数值支持。

### 同元素专精（用户认可）

借鉴《哈迪斯2》灌注：持有**两个带同一元素的按键**才出现/生效的卡，例如“冰左键＋冰右键时，被冻住的敌人再被另一个冰动作命中会碎裂”。保证单元素双觉醒没有反应也有完整的后期成长，卡的数量与双元素路线大致相当。

### 出口与地图

- 出口上**显示奖励类型**，并与 M 键打开的地图路线（杀戮尖塔式：普通战斗、精英、事件、休息、宝箱、商店、区域 Boss）**一一对应**：在地图上选的节点就是下一间。
- 房型对应的奖励（初值，最终放配置）：

| 房型 | 清场 / 进入后得到 |
|---|---|
| 普通战斗 | 构筑卡三选一（普通/稀有为主） |
| 精英 | 构筑卡三选一（史诗为主） |
| 区域 Boss | 第一区 Boss 后：**第二次元素觉醒**；其他区 Boss：传说品质三选一 |
| 宝箱 | 强化（已有卡升一级）或稀有：元素觉醒 |
| 事件 | 随机事件，可能给元素觉醒、卡、金币、回血或带代价的选择 |
| 休息 | 回血或强化二选一 |
| 商店 | 用局内金币买卡 / 强化 / 回血 |

- 一局三区、约 30 分钟，按每间 60–90 秒估算**每区约 8–10 间**（现有地图预览是 15 层，需要按区缩短）。一局大致：元素觉醒 2 次（稀有第 3 次）、构筑卡 10–12 次、强化 3–4 次。

## 1. 玩家应当获得什么体验

一局成长方向：**找到喜欢的主打法 → 改变技能使用方式 → 加入条件或动作配合 → 补齐弱点 → 获得能强化这套循环的后期机制**。

- 玩家偏爱右键剑气或R重击，可以持续围绕它发展，不必把三个动作平均投资。
- 单元素专精与双元素反应均须有完整的成长空间。单元素不强制购买第二元素才能获得后期机制；双元素路线也不要求继续凑齐四元素。
- 同一个冰核心能走远程控制、蓄力爆发、近身追击或冰土碎冰等方向。路线是可组合能力形成的结果，不给玩家绑定不可更改的职业树。
- 同一组兼容组件可共存，例如贯穿、碎冰追击、乘隙斩；后续能继续深化主轴，也能补生存或另一个动作。具体互斥须有机制或预算理由。
- 单元素与双元素都应能应对群怪和Boss，但不要求数值完全相同。Boss无法硬定身不应令冰系循环整体失效。

**机制卡的判断标准：拿到后，玩家下一间房会改变什么行为？** 可以是瞄准排线、预判回程、等待蓄力、控制后近身、聚怪再引爆、选择区域内作战。单纯伤害/半径/时间增加通常仍是数值强化；若确实跨过了战术阈值，需要在试玩中证明。

## 2. 构筑的五种作用，分别管理

| 作用 | 玩家在决定什么 | 示例 | 规则 |
|---|---|---|---|
| 元素核心 | 这个动作附着什么元素 | 冰剑气、土重击、火普攻 | 只来自“元素觉醒”（第 0 节）；每个动作最多一个，**不出现替换**；可以两个按键同元素。 |
| 动作/形态改造 | 这个动作怎么打 | 贯穿、回旋、蓄力、扇刃、命中爆炸 | 与元素核心独立；兼容的改造可共存，不把所有改造塞进一个互斥槽。 |
| 流派协同 | 怎样使用已有动作更有效 | 控制后追击、剑气后接普攻、自己的冰路上加速、控制获得防护 | 可以服务单元素或跨动作；有真实前置、来源、触发与消费条件。 |
| 反应改造 | 怎样围绕两元素安排战术 | 过载留下区域、碎冰产生一次有限余波、磁暴后制造输出窗口 | 基础反应无需此卡；后期应包含行为变化，不只反应伤害和范围增加。 |
| 数值支持 | 补足当前方案强度或容错 | 伤害、层数、持续时间、已有卡升级 | 保留，但不能让中后期主要奖励只剩数值。每次升级必须有实际收益。 |

以上是设计职责，不是要求新增五个装备槽，也不等于现有JSON的 `layer`。**品质、rank、动作绑定、槽位/互斥、奖励来源、设计职责各自独立。** 史诗或传说不自动等于机制卡，普通/稀有也可提供机制。

剑、弓、法杖可以有不同的形态卡目录；通用机制按实际载体能力复用执行器。例如贯穿服务可贯穿的剑气、箭和法术弹。元素卡复用实际动作/命中接口，不为“火剑气”“火箭矢”各写一套反应。

## 3. 与现有元素反应的关系

- 四元素、六反应继续保留。元素核心建立状态来源，形态改变命中方式，流派协同和反应改造决定怎样利用状态。
- 单元素可以围绕叠层、有效控制窗口、持续输出、区域、回程及防护发展；不以“无法发生双元素反应”为由剥夺后期选项。
- 双元素卡要求实际拥有两种有效元素来源；不能单凭卡名或标签让未实现的效果满足前置，也不默认授予第二元素。
- 例如冰剑气＋土重击：右键建立有效冰冻窗口 → R重击碎冰 → 利用后续奖励改变聚怪、余波或技能接续。这里的价值包含操作顺序和时机。
- 碎冰条件采用**土命中有效冰冻窗口**，普通敌人的硬冻结与Boss对应减速窗口均可满足；单独一层冰寒不满足。冰附着、冰寒积累、控制窗口、抗冻期由明确状态关联，不能因叠满时清空附着就丢失反应资格。
- 新反应改造必须说明：消费什么、何时消费、伤害来源、目标去重、触发次数和是否允许派生再次反应。首个切片中，反应衍生的区域/余波只执行声明的效果，默认不再附着元素或触发新反应。
- 既有破冰重击与冰土碎冰若都消费同一窗口，须明确一次消费和优先级；不得同一状态被两套逻辑重复兑现。

## 4. 一局选择示例：先建立同一基础，再自由发展

以下八次选择只用于说明成长体验，**不是固定卡序、保证掉落、八房限制或当前短冒险必须一次实现的全部内容**。下列旧卡能否使用新 `ice_core` 满足前置，必须完成适配后才能标为可玩。

| 选择 | 单元素冰剑气示例 | 玩家行为变化 |
|---|---|---|
| 1 | 冰剑气核心 | 右键命中积累冰寒，逐渐建立控制窗口。 |
| 2 | 贯穿 | 引导敌人排线，让一发覆盖多个目标。 |
| 3 | 碎冰追击 | 先用一次施放建立窗口，再用后续剑气追击；同一次施放附冰不自触发追击增益。 |
| 4 | 蓄力剑气（也可选择回旋发展另一方向） | 根据敌人前后摇选择点放或蓄力；回旋路线则重视回程站位。 |
| 5 | 冰霜路径 | 用飞行路径组织走位、限制追击者。 |
| 6 | 冰衣 | 控制成功提供有限防护，增加反打机会。 |
| 7 | 霜路疾行类协同（设计示例） | 主动留在自己铺设的区域内移动与作战。 |
| 8 | 寒潮回响类后期机制（设计示例） | 合法直接命中积累有限进度，为下一发附带一次延迟寒潮；利用聚怪与出手方向，派生不自充能。 |

同样在中途，玩家可以选乘隙斩，发展“剑气控制→近身普攻”；也可以在第6次附近选择土重击，转向“冰剑气→土重击碎冰”。后续再选择碎冰余波类机制及生存/循环支持。**放弃第二元素应当仍有值得拿的单元素选项。** 同一轮没选的兼容卡以后仍可再出现，选贯穿不代表永久放弃乘隙斩。

后期机制例子的名称和最终参数待试玩；不能仅把当前 `reaction_boost` 的百分比改大，就宣称已完成这些机制。

### 一次三选一应提供什么差异

玩家已有冰剑气，且合法来源/品质允许时，可面临：

| 候选 | 选择理由 |
|---|---|
| 贯穿 | 改善排线清群，继续主攻剑气。 |
| 乘隙斩 | 增加控制后近身普攻的配合。 |
| 冰衣 | 补生存与反打容错。 |

这是一次“成长用途”的示意，不要求每次固定一张输出、一张联动、一张生存。元素核心、动作改造可能来自不同奖励入口，不能为了复制示例而突破品质、前置或来源规则。

## 5. 候选生成：支持偏好，保留变化

1. **先判合法性**：实际动作/载体、元素来源、状态能力、依赖、互斥、槽位、有效升级和当前revision。能用于旧冻结核心不等于能用于新冰元素，须查询实际执行能力。
2. **再筛奖励来源与品质**：元素祝福按所选元素；武技改造按武器/动作能力；强化奖励只列有效rank提升。不能抽到立即无效的卡，也不能用空壳卡凑数。
3. **在合法池中增加相关候选机会**：根据已选动作和能力，适度提高继续深化的权重，保留补弱点和跨动作/第二元素的机会。偏好只影响候选，不暗改怪物强度。
4. **明确成长供给**：前期可建立主打法；中期持续有可达的形态/协同；后期有单元素和双元素各自的条件机制。阶段、权重和必要的类别保底来自JSON，不写死第几房必出某张卡。
5. **去重并锁定本轮候选**：避免三张只差一点数值；同一核心绑定不同动作可用于开局选择，但中后期不能反复用“冰普攻/冰重击/冰剑气”代替深化。相关类别不足时按显式策略给可用项，不无限重抽或赠送前置。

**“喜欢重击能一直玩”意味着相关深度足够、取得机会合理，不等于每次三张全是重击，也不保证每局拿到指定完整组合。** 不创建四元素各自复制一遍的树；用共享能力与有限依赖组织候选。

### 动作改造的获取渠道

按第 0 节，武技改造与元素被动、联动、反应卡一起进入**平时的全卡池三选一**，不再有“元素之祝福”出口，也不给通用贯穿伪造元素标签。训练预设用于快速测试，同时至少有一条实际奖励路线能取得所测组件。房间品质约束继续由配置管理；短原型如采用专用测试profile，要明确标为试用，不把 `training_all` 当最终奖励平衡。

## 6. 实现边界：在现有模块上补齐

| 模块 | 这次应做的事 |
|---|---|
| content / JSON | 定义卡的角色、实际能力前置、互斥与来源权重；同字段一个权威来源，同步schema/Loader。角色字段只在抽取或界面确实消费时加入。 |
| combat / BuildResolver | 编译元素与形态的组合、能力摘要和合法操作；元素核心与命中爆炸等改造分开校验，替换元素时明确处理失效依赖，不静默删掉整套构筑。 |
| combat / 执行器 | 将挂元素、改变轨迹、条件追击、区域、防护、反应效果组合；复用已有执行器，按职责补少量小模块，不按武器或卡名复制整套逻辑。 |
| rogue | 在combat给出的合法操作中，按来源、品质、成长用途和相关性抽候选。候选权重不能授予实际不存在的能力。 |
| app / Session | 协调领取、失败隔离、跨房重建与训练入口；不另写一套绕过Resolver的“流派一键完成”正式奖励。 |
| presentation | 双语说明“效果如何触发、需要什么、替换什么”，消费已提交事实；占位特效足够支持试玩。 |

- 规则事件保留施放/命中/来源、房间代数与动作快照；分裂、回程、反应区域各自明确继承和触发权限，维持根预算及目标去重。全局元素/反应强化继续动态读取，不冻结为旧施放时的数值。
- 元素来源与控制响应分开：Boss控制抗性不取消其元素身份；单元素追击与冰衣等读取有效窗口。
- 数值仍在JSON，表现仍在Resource。不引入任意JSON脚本、通用技能图编辑器或额外全局事件总线。
- 新类别/槽位需要兼容既有预设和内存跨房重建；旧冰卡只迁移此次需要的部分，不批量删除或一次重做所有内容。

## 7. 接下来实现什么

### 第一步：修正会妨碍试玩判断的问题

碎冰窗口条件、雷核心无效升级、元素与命中爆炸槽位冲突均已修正，见 [STATUS](STATUS.md)。接下来补明确的派生来源与继承权限；保留既有全局强化实时影响持续效果的行为。

### 第二步：做出两条能实际取得的成长样本

**已交付的基础协同切片（2026-10-16）**：碎冰追击、乘隙斩、霜径、冰衣已适配新冰核心，并通过正常候选领取与跨房重建验证；可与贯穿、回旋、蓄力共存。四张卡是兼容组件，不要求按固定顺序领取，也不要求第二个冰核心。碎冰追击限同动作较早独立施放，乘隙斩限另一正式动作；详细前置、品质和训练入口见 STATUS。以下后期新机制仍是后续目标。

- **单元素样本**：冰剑气＋贯穿＋控制后追击，继续发展蓄力或回旋中的一种，再加入路径或防护中的一种。优先适配已有代码；用新冰核心建立实际前置，不要求同时装备被替换的旧冻结核心。
- **双元素样本**：复用冰剑气基础，接土重击碎冰；补一个改变使用节奏的反应改造。建议先试“碎冰命中后赋予一次有时限的下一发剑气蓄力时间缩短”：仅玩家正式土动作成功碎冰触发，消费于下一次合法蓄力施放提交，有冷却与下限，不叠层，不改变普通瞬发剑气；需要真实蓄力能力。这是新增试用方案，不是已实现功能。
- 两条路线都可以加入数值支持和生存卡；比较结果要观察操作变化，不能只把第二条伤害调高后宣布更好。
- 接通武技改造奖励与合法候选，训练中能逐张领取。首个切片无需实现第4节示例中所有后期卡，也无需扩新元素、武器、区域或经济。

### 第三步：试玩后扩展

用户认可两条样本的操作与奖励体验后，再增加其他单元素路线、反应机制和后期选项。四元素不必各复制同样数量、同样结构的卡；复用机制，保留元素自己的打法。

## 8. 验收与交付

- 从空构筑逐次取得，能说明每次选择改变的行为；不能只依赖预装满配。
- 同一起点能走单元素专精，也能走双元素反应；单元素无需第二核心就有中后期可选内容。
- 取舍不是固定答案：偏重右键的玩家可持续深化；补左键/R的收益来自明确联动。
- 验证冰附着未满/有效冻结/Boss减速/抗冻四种条件；验证不会出现“没冻结能碎、冻结后不能碎”。
- 每张被列为rank升级的卡都有有效差异；不再发放雷核心同参数二级。
- 候选与提交使用同一能力检查，互斥/替换/跨房重建一致；任意顺序得到同一兼容集合时效果一致。
- 对新机制做匹配的来源、消费、暂停、死亡/切房、预算测试；六反应原有测试通过不等于成长路线验收通过。
- 交付列出：实际可玩卡、已适配旧卡、两条样本领取顺序及操作、奖励入口、JSON位置、测试与未验证范围。完成后同步STATUS和TECH。

本页没有承诺每局固定八选或要求全部旧冰卡复工。首轮交付目标是**让玩家从几次选择中感受到打法逐步成形**，之后再扩数量。
