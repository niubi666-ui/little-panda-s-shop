# 三选一与按动作构筑

2026-10-09。当前 Build schema **v7**，Combat schema **3**。已实现剑的三个同时可用动作与冰冻追击切片；数值权威在 `game/data/builds/prototype.json`。

## 试玩入口

- 店铺 F6 进入普通训练，或使用原有 `启动双动作测试.cmd` / `res://app/action_build_slice.tscn`（保留旧文件名）。完成开场三选一后，左侧「动作构筑预设」可直接切换。
- 左键 `primary` 三连击、R键 `special` 重斩、鼠标右键 `skill` 剑气、Shift 闪避。三攻击开局同时具备；鼠标右键 零前摇、基础冷却 1 秒，不需解锁卡。HUD显示Q冷却。
- 六组预设：基础动作；左键爆炸＋Q穿透冻结；Q寒霜爆破＋穿透；**冰冻＋贯穿、冰冻＋碎冰追击、冰冻＋乘隙斩**。
- 碎冰追击：先 鼠标右键 冻结普通敌人，冷却好后再 鼠标右键；当前单级直击增伤60%。乘隙斩：先 鼠标右键 冻结，再接近左键；当前单级直击增伤50%。成功命中显示浅蓝「追击 +百分比」。伤害无敌敌人不会显示有效增伤事实。
- 默认冻结1.2秒、剑气12米/秒，静止目标2米/6米均已验证第二发Q能命中窗口；抗性缩短冻结后不保证第二发Q赶得上，免疫仍生效。追击不解除、不刷新冻结。
- 顶部训练工具可追加敌人、恢复生命、切换伤害无敌和界面显隐；预设保留敌人、清理旧效果。重试清空Build但保留基础三攻击。专用入口T为隔离箭，L切语言。

## 已实现规则

- 选择保存 `selections[{upgrade_id,action_id,rank}] + revision`。各动作独立绑定；global明确作用角色。14项定义中11项进正常池，旧wave/chain/slow三项只用于调试夹具。
- 每动作至多一个核心。Q冻结换Q爆炸会移除旧核心，卡片显示移除项；已有冻结延长或追击依赖失效时拒绝替换，不自动删卡或退款。
- 碎冰追击要求本动作实际能施加冻结；乘隙斩要求另一个正式动作实际能施加冻结。直接和合法范围载体均有效，调试动作不提供前置。条件伤害修正本身不授予冻结。
- 读取命中前状态，必须由本玩家正式动作的更早独立根施放冻结；本根冻结、分裂子体、爆炸和调试/敌人来源均不满足追击。普通全局/动作伤害先算，条件加成统一加算限幅，再仅乘直接伤害；派生仍使用原普通伤害基数。
- 两卡可共存并兼容贯穿；贯穿逐目标检查状态。同动作穿透/分裂、寒霜/分裂仍互斥。冻结仅保留有效的一级；延长由独立freeze_duration负责。v6内容与旧冻结rank2明确拒绝，不静默截断，无磁盘存档迁移。
- 候选、预设、提交、替换、程序验证复用Resolver；先按升级ID加权抽取，再选合法动作，正常池不强制只出冰冻牌。失败/过期提交不改变状态或RNG。
- 单Runner：同帧闪避→鼠标右键→右键→左键；各动作冷却独立，special/skill开始重置连段。表现消费提交事实，关VFX不改变规则。
