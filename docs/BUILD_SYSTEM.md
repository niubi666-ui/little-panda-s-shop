## 当前能力与试玩

店铺F6进入训练；开场及清波按配置给三选一，“测试：再抽三选一”可连续测试。选择期间暂停，L切语言不重抽，Esc不跳过；满级/空池给提示。重试、回店或重开不保留本轮Build。

| 测试升级 | 实际作用 |
|---|---|
| 锋刃强化 | 攻击伤害加成，剑气继承施放伤害，不重复加成 |
| 轻盈步伐 | 正常移动速度，不改变闪避/击退 |
| 挥刀剑气 | 普攻生效时发射，挥空也可；默认碰墙/首次接敌结束，穿透升级改变敌人接触次数 |
| 回响连锁 | 普攻/剑气实损后触发，每施放至多一次，逐跳衰减 |
| 投射物分裂 | 已有合法投射物能力时可选；剑气和测试箭共用处理器，继承剩余寿命、快照与共同预算 |
| 命中爆炸 | 合法敌人接触触发，范围伤害受遮挡；默认不重复伤害直击目标 |
| 接触减速 / 接触冻结 | 附加持续控制，统一作用于近战与测试投射物 |
| 冻结延长 | 已有直接或明确范围冻结携带者时才出卡，强化后续施放时长 |
| 穿透 | 剑气/箭沿途命中不同敌人，有限次数与跨帧去重；与分裂互斥 |
| 寒霜爆破 | 给已持有且兼容的爆炸附加范围冻结；不授予全局直接冻结 |

等级替换旧级；卡片展示下一级完整效果。刀光测试仅切换美术；剑气球体、连锁线条仍是占位表现。

## 爆炸与控制入口

双击项目根 `启动机制测试.cmd`，或在Godot打开 `res://app/mechanism_slice.tscn` 按F6运行当前场景。先选开场卡，再在左侧菜单切换“穿透冻结 / 穿透普通爆炸 / 寒霜爆破”预设；T发箭，左键挥刀发剑气，L切语言。预设通过合法选择/编译路径替换Build，清掉旧投射物/状态但保留敌人；重新训练恢复战场并清空Build。店铺F6不进入此专用测试入口。

穿透爆炸每弹只有首次接触触发；寒霜爆破只明确冻结该爆炸范围，后续穿透不会自动冻结。冻结不能续时，解冻后有短暂抗冻窗口。具体操作、状态策略与验证见 [命中机制](COMBAT_MECHANISMS.md)。

## 测试箭入口

在Godot打开 `res://app/projectile_slice.tscn`，按F6运行当前场景（不是游戏内F6切换）。它复用庭院训练，普通训练入口不授予测试箭。

- 移动/瞄准仍沿用训练控制；**T** 沿角色朝向发射一枚占位箭，冷却/伤害在Build JSON的test_attacks中。
- 选择“试验 · 投射物分裂”；若首轮没出现，用“测试：再抽三选一”。验证独立箭时不要选剑气；选完向敌人发箭，接触后生成两枚子箭。
- 同时选剑气可对照两种投射物；重试清空本轮Build并保留测试入口。回店后通过店铺进入的是普通训练。
- 能力摘要不会因冷却暂时结束；当前没有运行中换装备接口。箭模型是Resource里的细长方体占位。

## 当前限制

- v4每升级一种effect_type；当前能力适配支持直线接触型投射物与有限同步范围payload；测试箭不等于完整弓职业。全局穿透/分裂对称互斥，尚无完整按动作绑定、主动AOE或任意效果图。
- 训练内存提交有隔离/失败回滚，正式Run与磁盘保存、候选恢复、清房奖励事务尚未接入。
- 平面扫掠以角色中心为受击点；玩家子弹不自动绕障。当前只有slow/freeze最小状态实例；完整通用Status与嵌套暂停服务尚未完成。
- 历史测试通过不代替当前验证；行为细节与验收清单统一在Build API维护，不在本页重复。
