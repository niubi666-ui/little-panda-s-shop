# 三选一与按动作构筑

2026-10-02。当前 Build schema **v5**，Combat schema **3**。已实现一把剑的双动作训练切片；数值以JSON为准。训练频率不代表正式冒险奖励节奏。

## 试玩入口

- 项目根 `启动双动作测试.cmd`，或运行 `res://app/action_build_slice.tscn`；选择开场卡后从左侧「动作构筑预设」菜单切换。
- 左键三连击，右键点击重斩，Shift闪避。剑气形态卡把右键替换为零前摇瞬发远程剑气，冷却1秒，挥空也发射，跳过近战和道具近战判定。
- 三组预设：**基础双动作**；**左键爆炸＋右键穿透冻结**；**右键寒霜爆破＋穿透**。
- T为独立测试箭，不继承左右键构筑；L切中英文。旧机制入口仍可打开，使用同一v5内容。
- 顶部「训练工具」展开玩家/敌人伤害无敌、恢复生命、追加敌人；「界面显示」控制面板显隐。重试清空训练Build，预设保留敌人并清理旧效果。

## 已实现规则

- 权威状态为 `selections[{upgrade_id,action_id,rank}] + revision`；同一升级可分别绑定primary/special并独立升级。global属性明确作用全身。
- 每个动作一个形态、至多一个核心；形态/核心/支持/协同依真实载体校验。14项定义中11项进入正式测试候选，旧挥刀剑气、连锁、减速3项仅为debug夹具。
- 同动作穿透/分裂互斥，分裂/寒霜互斥；不同动作独立。冻结强化必须找到本动作的直接或范围冻结载体，另一动作或T箭不满足前置。
- 候选、提交、预设、替换与程序防篡改复用纯评估器。替换后完整复验，有失效依赖则拒绝，不自动删除/退款。
- 候选锁定choice_id、动作、操作、等级、旧项与revision；升级ID先加权无放回，再选合法绑定。提交失败不改变权威状态及RNG。
- 每次施放截取动作/形态/修订版与效果；旧弹体不受随后选卡影响。子体保留根身份和预算，来源限制仍单独检查。
- 单Runner仲裁：同帧闪避→右键→左键，单槽缓冲、独立动作冷却；special开始重置普攻连段。取消许可来自JSON，取消不返还已开始冷却。
- 角色仍用idle/run，剑以Resource程序姿态区分重斩/发射。动作、投射物、拖尾、命中、终止、范围、状态可换PackedScene或显式关闭；表现不裁定伤害。
