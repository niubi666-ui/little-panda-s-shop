# 设计方向（草案 v0.3 · 2026-10-15）

> 这是讨论稿，用来决定接下来做什么。标“待定”的地方等试玩后再拍板。
> 数值都是起点，最终以试玩为准。
> 构筑成长方向已获用户认可，接续开发以 [构筑成长](BUILD_PROGRESSION.md) 为准；设计示例不等于已实现。
> 角色十属性、三类伤害和 C 属性页已接入原型，首版数值待试玩；规则与配置入口见 [角色属性与伤害结算](COMBAT_ATTRIBUTES.md)。

## 一句话

**像《哈迪斯2》一样砍怪、凑元素构筑的动作肉鸽；打完一局回到小熊猫的店里，用带回的东西经营、变强。**
战斗与构筑占 70%，经营占 30%。

## 三个支柱

1. **出手爽。** 每一下都有重量：清楚的前摇、命中顿帧、音效、击退。敌人也会出招，读招—闪避—反打是基本节奏。
2. **构筑逐步形成流派。** 选择持续改变出手、站位、目标和技能循环。火、冰、雷、土既能单元素专精，也能通过两两反应形成动作配合；数值支持两条路线，不能代替机制成长。
3. **店是家。** 一局结束回到店里，卖掉带回的材料，用钱换永久成长和装饰；店越来越像样。

## 一局的结构（目标 30 分钟）

| 段落 | 内容 | 时长 |
|---|---|---|
| 准备 | 店里选武器（先只有剑）、看一眼订单 | 1 分钟 |
| 第一区 森林 | 6–7 个房间 + 区域 Boss | 约 9 分钟 |
| 第二区 待定 | 6–7 个房间 + 区域 Boss | 约 9 分钟 |
| 第三区 待定 | 5–6 个房间 + 最终 Boss | 约 10 分钟 |
| 回店 | 结算、卖货、买成长 | 1–2 分钟 |

- 一个战斗房 60–90 秒，两到三波。
- **房间出口显示奖励类型**（和哈迪斯一样，玩家自己选下一间拿什么）：
  - **元素祝福**：从某个元素的三张卡里选一张。出口图标就是元素颜色，玩家能主动追一个元素。
  - **武技改造**：按当前武器和动作能力提供贯穿、回旋等改造；独立于元素归属（接续原型待加入）。
  - **强化**：把已有的一张卡升一级。
  - **金币 / 材料**：带回店里用。
  - **回血**。
  - **商人**：花局内金币买东西。
- 一局大约拿到 **10–12 次祝福选择、3–4 次强化**，仅为待试玩的节奏目标。历史八次选择模拟同样不是固定房数或卡序。
- 死亡或通关都回店；局内金币清空，材料保留。

## 战斗动作（沿用现有四个按键）

| 按键 | 动作 | 角色 |
|---|---|---|
| 左键 | 普攻三连 | 主要输出 |
| R | 重击 | 慢、重、破防 |
| 右键 | 技能（剑是剑气） | 远程或范围 |
| Shift | 闪避 | 位移与无敌 |

**元素和按键没有固定对应**（用户 2026-10-15 确认）：剑气可以是火剑气、冰剑气、雷剑气或土剑气，重击、普攻也一样，拿到哪种看局内选择。同一个元素也可以同时出现在几个按键上。当前元素绑定仅覆盖普攻、重击、剑气；闪避元素属于后续方向。

## 构筑的五种作用

| 作用 | 决定什么 | 示例 |
|---|---|---|
| **元素核心** | 动作附着什么元素 | 冰剑气、土重击、火普攻 |
| **动作/形态改造** | 动作怎么打 | 贯穿、回旋、蓄力、扇刃、分裂、命中爆炸 |
| **流派协同** | 怎么利用已有动作与状态 | 控制后追击、乘隙斩、冰路走位、防护 |
| **反应改造** | 怎样围绕双元素安排战术 | 反应留下区域、有限余波、反应后衔接下一次出手 |
| **数值支持** | 强度、容错与升级 | 伤害、持续时间、层数、已有卡升级 |

- 这是设计职责，不是五个装备槽；品质、rank、绑定动作、互斥、奖励来源各自独立。可玩状态以 [STATUS](STATUS.md) 为准。
- 元素核心与形态改造独立组合；兼容性由载体能力、触发权限和预算决定，不承诺所有改造无限叠加。共用能力复用执行器，不为每种元素复制一棵分支树。
- 一个动作同时只带一种元素，新的明确替换旧的（用户 2026-10-15 选定）。双元素卡要求已有两种有效元素来源，用来改造反应，不自动授予第二元素。
- 玩家可以一直深化剑气/重击或单元素，也可以补另一个动作形成配合。选了贯穿以后，兼容的碎冰追击、乘隙斩仍可再出现；中后期不能只剩百分比升级。
- 成长示例、抽取规则、兼容边界与首轮实施范围见 [构筑成长](BUILD_PROGRESSION.md)。

## 武器

先只有剑。以后计划加**弓**和**法杖**（用户 2026-10-15）。新武器沿用四个按键和元素接口，配置自己的基础动作与改造；通用卡依实际能力判断可用性，不保证所有卡无条件适用于所有武器。

## 四种元素

| 元素 | 状态 | 状态效果 | 手感关键词 |
|---|---|---|---|
| 火 | 灼烧 | 持续掉血，可叠层（上限 5 层） | 越打越痛 |
| 冰 | 冰寒 | 减速；叠满变为冻结（基础硬控 2.2 秒，Boss 改为强减速） | 控场 |
| 雷 | 感电 | 被下一次命中时向附近敌人弹射电弧 | 群体 |
| 土 | 碎甲 | 受到的伤害增加、更容易被击退和打断 | 破防、重量 |

每个元素先保证核心、单元素协同和后期机制有可达的成长链，再按试玩扩充数量；不要求各元素复制同样数量的卡。当前是一张元素核心定义绑定到不同动作，并非每个按键各写一份卡定义。

## 元素反应

一般由目标已有元素状态与新命中的另一元素匹配，满足该反应的条件后消费对应状态并结算。碎冰另需有效冰冻窗口；不把“拥有两张元素卡”当成反应已经发生。当前反应数值来自JSON；状态强度参与伤害的具体公式未定。

| 组合 | 反应 | 效果（初版） |
|---|---|---|
| 火 + 冰 | 蒸腾 | 单体大伤害，最直接的爆发 |
| 火 + 雷 | 过载 | 小范围爆炸并击退周围敌人 |
| 火 + 土 | 熔岩 | 地面留下一片熔岩，持续伤害 |
| 冰 + 雷 | 超导 | 范围减速，并让范围内敌人受到的伤害提高 |
| 冰 + 土 | 碎冰 | 土命中有效冰冻窗口时碎裂；Boss对应减速窗口也算，未叠满冰寒不算 |
| 雷 + 土 | 磁暴 | 把附近敌人吸向目标，方便聚怪 |

- **反应是基础机制**：合法命中满足状态条件即可触发，不需要专门的双元素卡；冰土碎冰还要求先建立窗口再用土触发。
- **双元素祝福**：拥有两种有效来源后进入候选，用来强化或改造对应反应。现有六张双元素卡仅提供数值强化，区域/余波/循环等机制须另做；单元素同样需要后期机制。
- 复用现有状态与效果执行器时可通过配置扩充；新增行为仍需实现执行器及校验，不能只加JSON卡名。

## 敌人：有来有回

- 每种敌人都有**能看清的前摇**，以及**一个必须用闪避应对的招**。
- **霸体与破防**：重装兵出招时带霸体，普攻打不断；重击或土元素能破霸体，破防后短暂硬直、受伤加深。
- **小兵会配合**：近战兵包夹，远程兵保持距离，旗手强化同伴（现有）。
- **Boss 有阶段**：半血换招式组合（现有游侠已有雏形）。

## 店里的部分（30%）

- **卖货**：局内带回的材料摆上货架，顾客来买，换成金币。初版只做简单定价，不做讨价还价。
- **永久成长**（类似哈迪斯的镜子/咒语）：用金币解锁更多祝福进入池子、提高初始生命、增加闪避次数等。
- **装修**：现有的摆家具系统保留，装饰带来小加成（待定）。
- **订单**：顾客点名要某种材料，交货给额外奖励，引导下一局去哪个区域。初版可选。

## 现有内容怎么处理

| 现有 | 处理 |
|---|---|
| 三连普攻、重击、闪避、剑气 | 保留作为基础动作 |
| 冰冻、寒印、冻结追击、乘隙斩、霜径、冰衣 | 按成长样本适配新冰核心的能力与控制窗口；不能只改名字就宣称可用 |
| 回旋、扇刃、蓄力、双拍、追踪、贯穿、分裂、命中爆炸 | 转为剑的形态改造（与元素无关） |
| 破冰重击 | 与冰土碎冰明确状态消费优先级；同一窗口不得重复兑现 |
| 冰棱遗落、寒潮回响等未实现的冰卡 | 先不做，元素原型试玩后再挑 |
| 品质分组、三选一、预设 | 保留，区分元素、武技、强化来源；预设之外必须能逐步取得成长组件 |
| 短路线、地图预览 | 发展成“出口选奖励”的一局结构 |
| 五种小兵、精英游侠 | 保留，按“有来有回”改造行为 |
| 火、雷、冰岩特效演示 | 直接用于元素祝福的表现 |

## 建议的落地顺序

1. **战斗手感**：音效、敌人有来有回。（已做第一版）
2. **元素基础与短冒险**：已有四张可绑定动作的元素核心、每元素3张被动、6张双元素数值卡，以及一个区域6间＋Boss的流程；尚不等于流派成长完成。
3. **当前优先：构筑成长切片**。碎冰条件、无效升级、槽位冲突已修正，武技已进入平时奖励；继续补派生来源权限与新冰核心对旧卡的适配，逐步取得“单元素冰剑气”与“冰剑气＋土重击”两条样本。全局强化继续实时影响既有元素效果。详细范围见 [实施顺序](BUILD_PROGRESSION.md#7-接下来实现什么)。
4. **试玩后扩展**：补其他元素的协同与反应改造，扩区域、房间和Boss。
5. **回店循环**：卖货、永久成长。
