# 当前状态

更新：2026-10-16。原型期，方向见 [设计方向](GAME_DESIGN.md)。构筑规则按 [构筑成长](BUILD_PROGRESSION.md) 第 0 节（元素觉醒、全卡池加权、同元素专精、地图出口）实现了第一版，待试玩。

## 怎么运行

- 引擎：Godot 4.7.2 标准版（Forward+），工程在 `game/`。本机路径 `E:/GoDot/Godot_v4.7.2-stable_win64/Godot_v4.7.2-stable_win64_console.exe`。
- 根目录的 `.cmd` 可以直接双击：

| 脚本 | 打开什么 |
|---|---|
| `启动游戏.cmd` | 主场景：店铺，按 F6 进战斗训练；左上角“进入冒险”开始一局 |
| `启动冒险.cmd` | 直接开始一局冒险（原型） |
| `启动森林遗迹战斗.cmd` | 直接进战斗训练（现在是童话森林场地） |
| `启动双动作测试.cmd` | 战斗训练 + 构筑预设菜单 |
| `启动机制测试.cmd` | 爆炸、冰冻、穿透等机制样本 |
| `启动路线测试.cmd` | 短分支路线：选节点 → 打房间 → 回地图 |
| `启动地图预览.cmd` | 随机冒险地图，只看不打 |
| `启动*特效演示.cmd` | 冰岩、剑气、落冰、雷电特效单独演示 |

**战斗操作**：WASD 移动，鼠标瞄准；左键三连击，R 重击，右键剑气，Shift 闪避；Esc 暂停/设置，L 切中英文，M 地图预览。

## 怎么试元素

- **冒险**：`启动冒险.cmd` 或店铺左上角“进入冒险”。
- **训练场**：`启动森林遗迹战斗.cmd` 或店铺按 F6 → 选完开场卡 → 左侧「动作构筑预设」里选 `蒸腾`、`过载`、`熔岩`、`超导`、`碎冰`、`磁暴`、`三元素`，或带被动/双元素卡的 `火流派`、`蒸腾流派`、`雷暴流派`，同元素专精的 `冰专精`、`火专精` → 按预设名字里写的顺序出招（例如“火普攻＋冰剑气”：先左键砍几下挂火，再右键剑气触发蒸腾）。

### 冰剑气协同（已接入，待试玩平衡）

- 碎冰追击（稀有，右键）、乘隙斩（史诗，左键）、霜径（稀有，右键）、冰衣（稀有，右键）已恢复正常卡池，权重各为 1。一个右键冰核心即可解锁四卡；乘隙斩也可由 R 的冻结能力解锁，不能用左键自己的冻结解锁。
- 碎冰追击：右键命中自身**较早独立右键施放**建立的冻结窗口 +60% 直接伤害；乘隙斩：左键命中**另一动作**较早建立的窗口 +50%。两者不消费冻结，不给分裂/爆炸增伤；同一发剑气回程不能追击自己。
- 霜径：剑气沿途留下 3 秒减速区域，不冻结；冰衣：右键实际建立窗口后给 20 点护盾，持续 4 秒、触发间隔 3 秒。普通怪冻结和 Boss 冰冻减速窗口都有效；冰寒未满、普通减速、寒印、抗冻失败都不算成功。
- **逐张试**：双击 `启动双动作测试.cmd`，选完开场卡 →「动作构筑预设」选基础动作以清空构筑 →「逐张领取（训练）」先选右键“寒冰附魔”，再分别领取四卡和贯穿。普通训练场先在顶部「界面显示」打开构筑面板。领取不会清掉已有卡，菜单只列合法新增/升级；冒险没有此授予入口，仍走三选一。
- 可与贯穿、回旋、蓄力共存。追击仍受冻结窗口时限限制，长蓄力不会延长窗口；霜径只有主投射物铺设，回程沿用同根预算。
- 验证入口：`tests/ice_synergy.gd`（真实命中、来源、Boss、盾和路径生命周期）；`tests/ice_synergy_rewards.gd`（奖励流种子 13，从真实觉醒和正常/精英候选逐张领卡、训练按钮、冒险跨房重建）。种子 13 是**测试中的选卡流种子**，不是可在现有冒险界面输入的地图种子。

## 已知问题

- **已修正与确认（2026-10-16）**：
  - 取消三选一的“暂时关闭”：有候选时必须选完，才能进入出口或下一笔商店购买，避免丢觉醒或重复购买同一候选。
  - 修复 Boss 遭遇缺少 `name_key` 导致的 HUD 脚本错误。三区 Boss 深度 9/13/18，对应生命 ×1/1.6/2.4、伤害 ×1/1.2/1.45；配置在 `data/rooms/encounters.json` 的 `depth_bands`。
  - 碎冰必须由土命中有效冻结窗口（普通怪硬冻结、Boss 冰冻响应产生的减速窗口）；未满冰寒、普通减速、寒印和抗冻期都不算，先土后冰不能碎冰。消费窗口后不能重复碎冰。
  - 元素核心二级加 15% 动作伤害；`impact_blast` 改为支援层；武技卡进入平时卡池。
  - 用户确认保留全局强化的实时读取：后续选卡可以影响仍存在的灼烧等元素效果，不列为 bug，不改成固定施放快照。
  - 验证：碎冰窗口、商店连续买卡/升级、三区 Boss 实际生成、五波训练等定向回归通过；Forward+ 下自动清怪跑通 24 房间至通关，未再出现 Boss 房脚本错误。此验证不代表难度平衡已验收；退出时仍有下述 Texture RID 警告。
