# 当前状态

更新：2026-10-15。原型期，方向见 [设计方向](GAME_DESIGN.md)。用户已认可 [构筑成长](BUILD_PROGRESSION.md) 方向，新增机制与奖励渠道待实施；本轮文档更新不代表代码已修复。

## 怎么运行

- 引擎：Godot 4.7.2 标准版（Forward+），工程在 `game/`。本机路径 `E:/GoDot/Godot_v4.7.2-stable_win64/Godot_v4.7.2-stable_win64_console.exe`。
- 根目录的 `.cmd` 可以直接双击：

| 脚本 | 打开什么 |
|---|---|
| `启动游戏.cmd` | 主场景：店铺，按 F6 进战斗训练；左上角“进入冒险”开始一局 |
| `启动冒险.cmd` | 直接开始一局冒险（原型） |
| `启动森林遗迹战斗.cmd` | 直接进战斗训练（现在是童话森林场地） |
| `启动双动作测试.cmd` | 战斗训练 + 构筑预设菜单 |
| `启动机制测试.cmd` | 爆炸、冰冻、穿透等机制样本 |
| `启动路线测试.cmd` | 短分支路线：选节点 → 打房间 → 回地图 |
| `启动地图预览.cmd` | 随机冒险地图，只看不打 |
| `启动*特效演示.cmd` | 冰岩、剑气、落冰、雷电特效单独演示 |

**战斗操作**：WASD 移动，鼠标瞄准；左键三连击，R 重击，右键剑气，Shift 闪避；Esc 暂停/设置，L 切中英文，M 地图预览。

## 怎么试元素

- **冒险**：`启动冒险.cmd` 或店铺左上角“进入冒险”。
- **训练场**：`启动森林遗迹战斗.cmd` 或店铺按 F6 → 选完开场卡 → 左侧「动作构筑预设」里选 `蒸腾`、`过载`、`熔岩`、`超导`、`碎冰`、`磁暴`、`三元素`，或带被动/双元素卡的 `火流派`、`蒸腾流派`、`雷暴流派` → 按预设名字里写的顺序出招（例如“火普攻＋冰剑气”：先左键砍几下挂火，再右键剑气触发蒸腾）。

2. **做出两条逐步成长样本**：[构筑成长](BUILD_PROGRESSION.md#7-接下来实现什么) 中的单元素冰剑气、冰剑气＋土重击；接通武技改造奖励、合法候选和逐张领取，训练预设不能代替实际获取。
3. **试玩后调节奏与扩机制**：元素数值在 `data/builds/elements.json`，冒险节奏在 `data/run/forest_run.json`；根据操作变化再扩其他元素机制。音效、轮流出手与破防继续随试玩调整。
4. **后续冒险与店铺**：商人/精英房、区域、冒险文字、金币接店、卖货与永久成长；先不为构筑样本扩这些系统。

## 已知问题

- **构筑成长缺口（接续开发前先复核，尚未修正）**：
  - 冰土碎冰目前可在一层冰寒时发生，叠满转成冻结后反而可能失去元素匹配；需统一有效冻结/Boss减速窗口与状态消费。
  - 雷核心二级与一级元素参数相同，当前会提供没有实际变化的升级。
  - `impact_blast` 仍占核心层，与元素核心互相替换；与“元素＋形态独立”目标冲突。
  - 元素被动/反应强化运行时读取当前program，既有灼烧会被后续选卡改变；施放、持续状态与区域的快照时点待落实。分裂命中目前也能挂元素，需显式声明派生继承和触发权限。
  - 新冰核心不等于旧冻结核心的能力摘要；旧追击/路径/防护卡不能据名称认定已兼容。当前元素出口过滤也不纳入通用贯穿/回旋，缺少武技获取渠道。
- **测试落后于流程**（2026-10-15 图形模式实测）：
  - `training_tools.gd` 两项失败：训练已改为五波，测试仍按两波写。
  - `golden_sword_trail.gd` 一项失败：期望刺击宽度 1.0，配置为 1.8。
  - `combat_feedback.gd` 一项失败：尸体保留/消散改动后断言未更新。
  - `action_build_integration.gd` 四项失败（followup fact 6–9）：首批冰冻扩展预设不再满足测试里“右键冻结后追击”的前提，之前就存在。
- 图形测试里引擎偶尔报 `Parameter "material" is null`（`material_casts_shadows`），测试本身通过，来源未定位。
- 退出图形场景常见 7 个 Texture RID 泄漏警告（疑似引擎问题），未证实影响帧率。
- 战斗场地暂不摆随机道具（道具还是卡通模型），见 [画面管线](ART_PIPELINE.md)。
- 没有正式最低配置和完整战斗帧率验收；RTX 4060 笔记本 1080p 战斗约 70 帧。
- 音效和元素表现只接在战斗训练场（冒险也是用它）；旧的短路线测试（`run_room.gd`）没有。
- 冒险模式下屏幕左侧仍是训练场的文字（“战斗训练·初版”“训练完成”等），左下“重新训练”在冒险里等于“再来一局”。
