## 实际处理

| 项目 | 数值 |
|---|---:|
| 头部高模三角面 | 1,863,861 |
| 原始低模三角面 | 24,474 |

| 相对高模减少 | 98.59% |

统计包含用户提供的头部素材中的长发、肩胸和衣领，不是单独脸部。

- 在源场景副本中操作，原始文件和身体网格、变换、材质槽保持不变。
- 仅对新增的头部副本修正法线，填补 187 个可自动封闭的缺面区域，并固定三角化。
- 保留原 UV 层，增加 `Head_BakeUV`：原有岛压入左侧 84%，补面独立排布在右侧，贴图按新层重新烘焙。不要把这些贴图直接套在原低模 UV 上。
- 使用 Cycles 高模到低模投射，射线起点外扩 0.012，最大距离 0.04（以该头部约 0.979 单位高的源尺寸计）。
- 生成 4096×4096 底色和切线法线；贴图已连接到材质并打包，外部 PNG 在 `textures/`。
- 法线为 OpenGL +Y，Non-Color，Normal Map 强度 1。底色为 sRGB，只烘焙颜色，不加入本次灯光。
- 法线 PNG 为 16-bit 母版，底色为 8-bit。后续可按游戏镜头另做 2K/压缩版本，本次没有接入或改动 Godot。
