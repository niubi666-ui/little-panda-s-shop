# 小熊猫 Auto-Rig Pro 绑定修复 v003

## 文件与操作

- Blender 文件：`../blender/red_panda_arp_v003.blend`，活动场景 `RedPanda_ARP_v003`。
- 使用 Blender MCP 调用已安装 Auto-Rig Pro 3.78.46 的 `arp.bind_to_rig`，HEAT_MAP 自动蒙皮后进行分区修正。
- 保留原有动画兼容骨架和五根尾骨，共 46 骨。不是重新生成 ARP 控制器骨架，也没有添加手指控制器。
- 原 v002 文件及源 FBX 未覆盖。
- 动作：RP3_idle、RP3_walk、RP3_run、RP3_jump、RP3_agree。

## 修复

1. 原头部高处有 114 个顶点受到手臂影响。按 UV 分区识别整个头部后，866 个头部顶点只受 Head 骨影响。
2. 脸颊与袖口/肩部有共享顶点，沿 27 条交界边拆分，顶点由 5074 增至 5101，保留 UV 与原贴图。此处为独立表面接缝，未做封口重拓扑。
3. 清理对侧手臂对衣服的影响，平滑肩颈，调整上躯干权重。
4. 保留 v002 的尾巴分段绑定和动作摆动；腰部小配件固定到腰部。

## 验证

- idle 369 帧、walk 57 帧、run 31 帧、jump 54 帧、agree 97 帧，共 608 帧逐帧检查；未发现无穷或非法坐标。
- 单独旋转双臂时，受保护头部顶点最大位移为 0；头部无非 Head 权重。
- 头部各动作最大边长比约 1.00004（浮点误差）；尾巴最大边长比约 1.115。
- 所有顶点有归一化骨骼权重。详细结果见 `arp_v003_validation.json`。
- 查看了五段动作的抽样视口图，导出了 `../previews/arp_v003_run.mp4`。数值逐帧检查不等同于所有视角逐帧艺术验收。

## 仍待精修

- 全身局部短边最大伸长比约 4.55–6.84，不能据此宣称肩袖、腋下和衣服已达到最终品质。
- 原 Tripo 手掌和肩部姿态仍有僵硬/变形；保留原动作，没有重做动作设计。
- 拆开的肩颈交界尚未封口，需要在最终镜头距离下继续检查大幅动作时的缝隙。
- 跑步保留源动作位移，循环切换可能回跳；尚未转换原地跑步或制定 Godot 根运动方案。
- 未验证 Godot 导出、碰撞、攻击挂点或游戏运行。

## 本轮处理脚本顺序（针对 v002 的新副本）

`rebind_arp_v003.py` → `refine_arp_v003.py` → `smooth_arp_v003.py` → UV 分区检查生成 `arp_v003_head_faces.json` → `split_head_arp_v003.py` → 再次 `smooth_arp_v003.py` → `torso_arp_v003.py` → `validate_arp_v003.py`。

脚本是本轮修订记录，不是可反复执行的通用导入器；拆缝脚本只能对未拆分的 v003 网格执行一次。
