# 小熊猫 Tripo v001：导入与动画检查

检查日期：2026-09-25。通过 Blender MCP 在 Blender 5.2.1 LTS 中导入并检查。

## 结论

骨架、蒙皮与一段动画均已导入，动画实际驱动网格变形。但动作中尾巴附近出现明显的大面积三角形拉伸，此版本尚未通过动画质量验收。

## 实测信息

| 项目 | 结果 |
|---|---|
| 骨架 | 1个Armature，41根骨骼 |
| 网格 | 1个网格，5074顶点，9564三角面 |
| 蒙皮 | Armature修改器正确引用骨架，30个顶点组 |
| 权重覆盖 | 未加权顶点为0，权重总和在浮点误差内约为1 |
| 动作 | `Armature\|afraid.001`，第1–63帧 |
| 导入场景帧率 | 24 fps；这是当前导入结果，尚未核对Tripo源动作时长 |
| 贴图 | 一张4096×4096彩色贴图，已成功加载并打包进检查工程 |
| 尾巴 | 骨骼列表未发现独立尾巴骨链，需要进一步检查尾部顶点的实际权重归属 |

第1、16、32、48、63帧抽样确认网格顶点位置变化。权重覆盖完整只证明有绑定，不代表绑定到正确部位；第16、32帧的视觉结果显示严重拉伸。疑似尾部网格错误受肢体骨骼牵动，确切原因需进一步逐顶点检查权重及原始网格，不能仅凭截图定论。
