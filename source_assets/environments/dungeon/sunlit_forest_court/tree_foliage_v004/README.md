# 圣树低面数候选 v004

目标：树冠不超过 3000 个三角面。结果：2928 三角面，树干 19032，总计 21960。树冠由 v003 的 240584 面减少 98.783%。v003 原始文件保留。

## 实际实现

1. 对 v003 的六种立体叶团进行四方向正交捕获，生成 24 个透明颜色区域与对应方向的法线区域。
2. 颜色通过材质发光输出捕获，未将评审场景的固定灯光烘入；源图集自身已有的局部明暗仍会保留。
3. 相机空间法线转换为每张卡片对应的切线空间方向，背面朝向翻转到可见半球。图集尺寸均 3072×2048，单区域 512×512。
4. 每个叶团以 4 张轻微弯曲卡片（32 三角面）与 8 片边缘叶（16 三角面）组成，共 48 面。61 个实例共享六份网格。
5. 写入 POINT/FLOAT_COLOR 属性 wind_rgba：R 局部弯曲权重，G 模块相位，B 变化值，A=1。尚无风吹 shader，不能视为已完成风动。

## 视觉结论与边界

已达到几何预算，但并非零损失。近景能看到卡片交叉和层叠，叶团遮挡、厚度、细叶轮廓及阴影与高模不同；较适合进一步评估为远景 LOD 候选，不能直接宣布通过当前游戏视角美术验收。

没有按固定百分比删除所谓“不可见面”：可见性和阴影贡献随相机/光照改变。本轮直接从保存的高模烘焙并重构低模。没有跨卡片焊接 UV 边界或风动边界。未修改 Godot，未实现 LOD 切换、性能基准或风 shader。多层透明像素仍有成本，不能依据三角面降幅推断帧率提升。

制作中一次并行渲染触发 CUDA 驱动访问错误；已改为顺序处理，最终烘焙/渲染进程正常完成。失败未覆盖高模或原始树干。
