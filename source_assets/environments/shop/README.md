## 工程组织

| 集合 | 内容 |
|---|---|
| Architecture | 墙、窗、梁柱、护墙板 |
| Floor | 独立石板、灰缝与裂纹细节 |
| Furniture | 柜台、货架、入口门、展示台、地毯 |
| Merchandise | 箱桶、宝箱、补充陶罐 |
| Plants | 盆栽、垂藤 |
| Details | 灯具模型、挂毯、装饰与金属件 |
| Lighting | 太阳、窗光、室内补光与灯芯 |
| Cameras | 正交展示相机 |
| Presentation_Only | 体积雾、仅遮光的顶棚，不应直接作为游戏几何导出 |

物件采用英文名称；原始物件带 source_file/source_object 元数据。摆放记录见 `reports/shop_art_placement_manifest.json`，该文件是美术制作记录，不是游戏装修规则配置。

## 进入 Godot 前仍需处理

这次交付为**可编辑的 Blender 场景美术原型与离线渲染**，尚未作为 Godot 实机画面验收。

1. 程序材质需要烘焙到 PBR 贴图，或在 Godot 中重建对应材质；Cycles 灯光、雾和反射不能直接等同于引擎效果。
2. 地板/墙模块及藤叶可按实际视野合并或实例化，减少运行时物件和绘制提交；保持可装修家具独立。
3. Tripo 柜台和展示台本身是聚合网格，商品尚未逐件拆成可售卖节点。门与宝箱开合也需进一步拆分、设置转轴。
4. 入口目前是关闭门的美术摆放，尚未完成可通行门洞、碰撞、导航、装修格子和交互点。
5. 需与最终主角及正常比例顾客一起核对柜台高度、通道宽度、镜头遮挡和可读性，再制作游戏表现资源。
6. 降面柜台需要近景进一步检查；当前按本次正交镜头进行了视觉检查，未承诺近距离特写质量。
7. 商用素材授权凭据尚未在本文件夹归档，沿用用户提供来源，待项目发布前补齐。

## 重建

在原始 item1.blend 的后台副本上依次运行：

- `scripts/build_shop_v001.py`
- 加载 v001 后运行 `scripts/refine_shop_v002.py`
- 加载 v002 后运行 `scripts/refine_shop_v003.py`
- 加载 v003 后运行 `scripts/refine_shop_v004.py`

脚本用于本轮确定资产清单的重建，不是通用导入器；重复应用同一迭代脚本会重复创建细节。`inventory.py` 仅制作资产联系表。
