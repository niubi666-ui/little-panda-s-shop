三、三张样板的视觉设计（参数是可调初值，不是性能保证）

火焰附魔 / fire_core
  静止区域：刀柄、护手、刀身主体、背景建筑、地面和花草。
  动区：沿原画既有火焰方向做局部轻微流动；刀缘橙金色亮度缓慢起伏。
  在既有燃烧区域发出少量细小火星，略向上/右漂，渐隐；不要从整幅画随机喷火。
  初值：局部扰动 1–2 个卡面逻辑像素；亮度起伏约 ±8%；同屏单卡 8–14 粒火星；寿命 0.8–1.6 秒。
  节奏：约 4 秒的柔和起伏叠加不同相位的小变化，不做同步明灭。

寒冰附魔 / ice_core
  静止区域：武器实体和森林建筑。
  动区：现有冰晶与刀锋边缘零星扫过细光；少量透明寒雾缓慢掠过刀身下侧。
  避免把整片蓝色区域扭曲成水面；冰要坚硬、锐利、冷而清透。
  初值：寒雾不透明度 0.05–0.12，漂移 3–6 个卡面逻辑像素/秒；每次 2–4 处小闪光，渐入渐出 0.35–0.6 秒。
  节奏：约 5–6 秒，光点错峰，背景仍保留暖光森林色彩。

雷霆附魔 / thunder_core
  静止区域：武器实体、主体轮廓与森林背景。
  动区：沿刀身和画内已有电弧布置可编辑路径，间歇出现短电弧与极少分叉。
  电弧限定在插画内部；不要用整张图曝光闪白表现雷电。
  初值：一次放电 0.12–0.22 秒；两次间隔 1.8–3.2 秒；单次 1 条主弧、最多 2 条短分叉；细而清楚。
  低亮度电纹可缓慢流动，明显放电错相；三张雷卡同屏也不同时闪烁。

四、共用表现与独立图层
1. 图层次序：原画 → 局部效果/微粒（限定插画窗口）→ 原有底部渐隐 → 独立装饰/边框 → 文字。
2. 当前悬停抬起和聚焦光晕继续使用。悬停只把原画动态强度柔和提高约 15%，不新增放大摇晃；可随总强度关闭。
3. 品质边框依旧按普通银白、稀有蓝、史诗紫、传说橙金，不随元素改色。元素靠原画内部辨认。
4. 文字、收益数值、按钮和下方植物纹样保持稳定；火星、电弧、寒雾不得盖到正文。
5. 首轮不拆背景做视差：避免拉伸补洞和刀身漂浮。图内动效靠局部遮罩与叠加完成。
6. 开关关闭时恢复原有静态原画；不得把最终动画烘焙成带字的整张卡牌视频。

五、技术建议（由实施者结合实际接口细化）
使用独立 CanvasItem Shader / 局部叠加层 + 少量 2D 粒子，尽量复用三类模板。
每张配置放 Resource：效果类型、强度、速度、颜色、遮罩/路径、粒子发射区、随机相位和静态开关。
建议新目录：game/presentation/builds/card_art_motion/；新增美术放 game/assets/ui/build_cards/v001/motion/。
源遮罩/路径、调参记录、对比视频归档到 source_assets/ui/build_selection/animated_v001/。
遮罩必须独立于原 PNG；建议为每张建立独立的刀锋/发光/粒子范围，可用可编辑多边形与路径实现。
不要只靠全图亮度或蓝色阈值提取动态区域，会误伤天空、水面和背景高光。
如果使用纹理遮罩，必须与原图使用完全相同的 UV / KEEP_ASPECT_COVERED 裁剪；适配不同品质的插画起始高度。
ShaderMaterial 按卡实例分开，避免改一张影响其他卡；底层纹理可共享。
原画时钟显式注入，不用无法控制暂停/重置的全局 TIME。只在选卡界面可见时推进。
选卡本身冻结战斗但 UI 应继续播放；另行打开暂停/调试冻结时按现有 UI 状态冻结；隐藏或退场释放后停止粒子和计时。
视觉随机使用独立 RNG / 配置 seed，不能消耗奖励、战斗的随机流。
每卡初步限制 1–2 个效果覆盖层、1 个小粒子发射器、最多 24 个活跃粒子；不为每卡建 3D 场景或播放高分辨率视频。
这些仅是设计预算；实际用相同机器、同一三卡场景对比静态与动态 GPU/帧耗时，报告测量条件，不空口保证帧率。
其余卡牌显式映射为静态；已声明动态却缺资源时应报错，不用隐藏默认值掩盖配置错误。
