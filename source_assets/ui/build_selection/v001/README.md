## 品质与状态

| 美术 ID | 品质 | 主边框色 | 形态 |
| --- | --- | --- | --- |
| common | 普通 | 珍珠白／银白 | 简洁细边、少量叶饰 |
| rare | 稀有 | 蓝 | 蓝色金属外缘和克制轮廓光 |
| epic | 史诗 | 紫 | 紫色外缘、较丰富角饰 |
| legendary | 传说 | 橙金／琥珀金 | 月桂冠式顶部叶饰、金色边缘光 |

所有品质共用深绿标题区和浅羊皮纸正文区；品质色主要作用于外边框和品质文字。保留中文／英文品质名称帮助辨认。传说的冠饰增加形态差异。

品质与技能升级等级是两个字段。概念图中技能对应的品质仅为展示，尚未给现有技能确定品质或倍率，也不表示每次抽取必有蓝、紫、金各一张。

悬停／键盘焦点保留本卡品质色，以边角标识和小幅亮度变化表达，不能把所有卡的焦点边框都改成金色。图中中间卡示范焦点状态，不表示已经提交选择。

## 实现时的布局要求

- 三张卡等高等宽，刷新按钮位于整个卡组下方居中，不能随某张卡一起移动。刷新文字建议“刷新选项 / Refresh Choices”。
- 卡片可依次呈现品质、技能图标、名称、等级／新能力、效果详情和选择动作。正文深色字搭配浅纸底，装饰集中在边缘。
- 概念中的图标和简短说明用于观感评审。实际长描述应缩小图标区域，标题允许两行，正文留约 7–9 行；更长内容需有明确阅读方式，不能裁切或缩到难读。至少在项目现用 1280×800 与 1920×1200 下校验。
- 当前界面包含 rank/max_rank 与目标等级。正式排版应保留真实数据，不能因概念只展示简化等级而丢字段。
- 刷新默认深绿古金；悬停稍提亮边框；不可用降饱和度。刷新费用、次数限制、消耗方式尚未指定，所以本次不设计固定价格或次数。
- 正式皮肤拆分时，将四品质边框、纸张底、技能插画、刷新按钮底和循环箭头分别制作；动态文字、等级与效果走翻译系统。沿用项目 Noto Serif SC 字体体系。
