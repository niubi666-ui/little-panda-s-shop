## 共用信息与交互要求

- 四品质为普通白、稀有蓝、史诗紫、传说橙金；颜色之外保留品质文字和装饰形态差异。
- 卡片保留品质、技能图标、技能名称、新能力／升级等级、效果说明与选择按钮。正式界面还须呈现真实的当前等级、最高等级（`rank/max_rank`）与目标等级，不能因示意图的简写丢失字段。
- 品质与技能升级等级是不同字段。图片中的技能、品质分配及效果文字仅为排版示例，不是技能品质表、数值配置或候选抽取规则。
- 三张卡等高等宽；刷新按钮位于整个卡组下方居中。刷新费用、次数、消耗及提交规则尚未确定，不能从示例图推导玩法规则。
- 卡片悬停／键盘焦点应保留其品质色，通过边角提示或轻微亮度变化表达。刷新按钮需有默认、悬停、不可用状态。
- 标题允许两行，正文为长效果说明预留空间。实际接入须校验中英文、字体缩放和长文本；参考原版的 1280×800 与 1920×1200 布局要求。

## 交付边界

本目录交付完整美术概念图和本地比较页。图片含背景与示例文字，**不是透明切片、可直接套用的 Godot Theme 或游戏实机截图**。本轮没有实现新的品质系统或卡组内刷新功能，也没有修改 Godot 场景、脚本或资源。

正式皮肤制作时，边框、底板、图标、刷新按钮底与循环箭头需要拆分；所有玩家文字、品质名称、等级和效果说明都应由动态界面与项目本地化系统呈现，不将概念图文字烘入正式皮肤。沿用项目 Noto Serif SC 字体体系。

原版说明与既有功能边界见 [v001 README](../v001/README.md)。本轮生成参数及源文件追溯统一记录在 [generation/prompts_and_sources.json](generation/prompts_and_sources.json)；图片观感验收不代表游戏功能验收。
