## 需要转译成 Godot 控件的美术特征

- 主面板为深森林绿；细古铜边框和少量金色高光勾勒层级；物品详情允许羊皮纸色块。
- 树叶和藤蔓主要出现在边角、标题附近及少量按钮端部，保留足够留白，不遮挡文字或游戏场景。
- 文本用暖白色，按钮状态通过边框、亮度、轻微深度变化及图标共同表达，不能仅靠颜色。
- 物品图标有细腻手绘质感；图标、按钮、边框和文字应分层制作，以便动态内容、双语和分辨率缩放。
- 店铺 HUD 避开房间中央交互区域，常用信息放屏幕边缘；弹窗打开时适度压暗背景。

## 功能与内容边界

- 订单允许接 **0 或 1** 张；玩家可以不接订单直接进入地牢。
- 图片中的金币、生命、物品、价格、世界观文案、快捷键及数量是占位示例。`02_inventory.png` 的容量数字与可见格子也未严格一致；以项目内容定义、输入配置和运行状态为准。
- 图片中的中文为概念文案；正式界面使用本地化 key 和命名参数，验证英文长度。不要把文字烘焙到界面贴图里。
- `05_ui_components.png` 中的确认弹窗只演示外观；哪些操作需要二次确认由交互设计决定。
- 这套参考锁定**视觉方向**，并不冻结每个窗口的最终布局、控件尺寸和交互流程。可根据真实分辨率、鼠标命中区域及可读性调整。

## 可直接发给开发 AI 的任务说明

> 请以 `source_assets/ui/reference/foliage_v001/` 的五张图作为已选 UI 美术方向，先读 `PROJECT_CONTRACT.md` 和 `美术方向基准.md`，再检查 `game/` 现有场景与代码。使用 Godot 原生 Control、Theme、StyleBox、NinePatchRect 等可维护组件实现界面；保留深绿、古铜、羊皮纸与克制的树叶纹饰。图片是概念稿，不要整张贴在游戏里。所有文字通过本地化 key 动态显示，数值来自运行状态或配置；遵守模块边界。先实现一个可运行的纵向切片并用 Godot 实机截图与参考图对照。
