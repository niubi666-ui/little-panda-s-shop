# 完整设置／暂停菜单 v002

本版按用户纠正重新设计：设置菜单必须包含音量、语言、画面、按键以及保存、读取、退出操作。v001 的操作帮助布局不再是主菜单设计，只可作为操作指南子页参考。

## 文件入口

- `reference/settings_full_concept.png`：完整综合设置页概念图。
- `exports/chrome/`：12 张透明无字 PNG。
- `exports/icons/`：17 个 SVG 图标及辅助底板。
- `previews/index.html`：设计图与所有拆分素材图库。
- `manifest.json`：尺寸、透明外边距对应 Atlas 区域、来源与 SHA256。
- `reports/asset_validation.json`：透明通道、SVG XML、引擎副本一致性检查。
- 引擎副本：`E:/ShopGame/game/assets/ui/settings/v002/`；对应 `res://assets/ui/settings/v002/`。

这是美术资源和交互提案。本轮没有修改 Godot 逻辑，没有实现音量、画质、存档、退出或重绑定功能。图中 80%/60%/85% 只是概念样例，不是正式默认数值。生成使用内置 imagegen，提示词见 `generation/prompts.json`。原 PNG 字节保持不变。

## 菜单内容规划

| 页面 | 内容 |
| --- | --- |
| 综合设置 | 主音量、音乐、音效、界面语言；常用窗口模式与垂直同步快捷项 |
| 画面设置 | 窗口模式、分辨率、垂直同步、帧率上限、画质预设；按实际支持情况开放阴影、抗锯齿等细项 |
| 操作与按键 | 实际按键展示、鼠标／镜头灵敏度、恢复默认；重绑定需实现后才启用 |
| 存档管理 | 滚动存档列表、槽位选中、截图占位、时间、游戏进度、保存／读取按钮；空槽、无效槽与读取失败状态 |

左侧页签切换，右侧羊皮纸承载内容。综合页和画面页重复展示的窗口模式等字段必须引用同一个设置值。底部固定：返回游戏、保存游戏、读取存档、退出游戏。保存／读取打开同一个存档管理页并进入对应模式，不维护两份独立列表。

用户明确要求的功能是设计目标；具体画质选项、按键重绑定、槽位数量和何时允许保存仍需由后续实现结合项目能力决定。不要因为概念图出现了控件，就显示虚假的“保存成功”或让无效选项看似已生效。

## 拆分素材与装配

- 主框 `window_panel.png`；内容纸 `controls_parchment.png`（沿用文件名，可用于所有设置页）；标题叶饰 `header_leaf_sprig.png`；关闭底板 `close_socket.png`。
- 导航页签和下拉按钮底板复用 `tab_regular.png` / `tab_selected.png`。下拉箭头使用 `chevron_down.svg` 独立叠加；下拉列表内容由真实控件生成。
- 音量滑杆：`slider_track.png` + `slider_fill.svg` + `slider_thumb.png` 三层。填充按范围裁切，滑块由实际数值定位；不可把整条带滑块的图片当作调节控件。PNG 带大透明边距，先按 manifest 建 AtlasTexture。
- 勾选框：`keycap.png` 缩为方框底板，加/减 `check.svg`；禁止把勾与底板烘焙在一起。
- 主按钮 `button_primary.png`；保存和读取 `button_secondary.png`；退出 `button_exit.png`。图标、标签和底板独立。
- 存档行 `save_slot.svg`；可选中时叠加 `focus_ring.svg` 或引擎主题框；截图、时间和进度由节点单独填充，不能烘焙样例数据。
- `monitor.svg`、`gamepad.svg`、`save.svg`、`load.svg`、`exit.svg`、`speaker.svg`、`language.svg` 提供分类与行为图标。
- 焦点、悬停、按下、禁用由控件状态管理；焦点必须区别于“当前语言/页签已选中”。禁用不能只靠降低透明度，还应有原因提示。

概念图左下角的小熊猫插画为生成图的附加装饰，不是本包独立素材。实现可以留白或使用现有叶饰，不影响布局与功能。

## 交互与工程交接

1. 字体沿用项目 Noto Serif SC。所有玩家可见文字走翻译 JSON，百分比、时间和槽位名作为命名参数；图像不含文字。英文标签预留伸展空间。
2. 点击返回或 Esc 返回游戏。菜单期间隔离战斗/装修输入；暂停状态与背景动画是否继续由游戏流程协调。
3. 音量可实时试听；设置持久化需明确实现。画面选项中分辨率/窗口模式应用后应有确认倒计时，未确认恢复之前的有效配置。
4. 保存先选槽，覆盖已有存档时确认。保存失败不能显示成功，不能改变权威游戏状态或丢失旧存档；遵循 PROJECT_CONTRACT 的会话提交入口。
5. 读取存档前提示当前未保存进度；不可把兼容性失败当成损坏静默回退。战斗中是否允许手动保存应由规则明确决定。
6. 退出前提供清晰的未保存进度提示。可提供“保存并退出／不保存退出／取消”，但只有真实保存成功才执行前者退出。
7. 恢复默认只重置当前设置域，不删除存档。声音、画质、语言和键位的默认配置需要有唯一权威来源。
